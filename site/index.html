TUN macOS

接管不走系统代理的程序，首次开启时需要一次管理员授权。Route traffic from apps that bypass system proxies, requiring admin permission once.

在菜单栏（Windows 和 Linux 上是系统托盘）切换接管状态、模式与出口节点，图标不显示跳动的网速。Switch proxy status, modes, and exit nodes from the menu bar, or the system tray on Windows and Linux, without jittery speed numbers.
